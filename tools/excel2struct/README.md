# excel2struct

기획자의 Excel 파일을 분석하여 게임 서버용 **Go 디자인 struct 코드**를 자동 생성한다.

## 디렉토리

```
tools/excel2struct/
├── excel2struct.py     # 변환 스크립트
├── requirements.txt    # Python 의존성 (pandas, openpyxl)
├── input/              # xlsx 입력
│   ├── cards.xlsx
│   └── skills.xlsx
└── output/             # .go 출력
    ├── card_design.go
    └── skill_design.go
```

## 설치

```bash
cd tools/excel2struct
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 사용

```bash
# 기본 실행
python excel2struct.py

# 패키지명/경로 지정
python excel2struct.py --package design --input-dir ./input --output-dir ../../internal/design
```

## 변환 규칙

### 파일명 → 타입명

| Excel 파일명 | Go 타입명 | 출력 파일명 |
|-------------|-----------|------------|
| `cards.xlsx` | `CardsDesign` | `cards_design.go` |
| `skill.xlsx` | `SkillDesign` | `skill_design.go` |
| `BAT_DATA.xlsx` | `BatDataDesign` | `bat_data_design.go` |

> 파일 stem을 PascalCase로 변환 후 `Design` 접미사 부여.
> 이미 `Design`으로 끝나면 중복 부여하지 않음.

### 컬럼 → 필드

- `card_id` → `CardId`
- `base_atk` → `BaseAtk`
- `name` → `Name`
- 숫자로 시작하는 컬럼은 `F` (Field) prefix 부여:
  - `2B` → `F2B`
  - `3B` → `F3B`
  - `1ST_GRADE` → `F1stGrade`

JSON 태그는 원본 컬럼명 그대로 부여 (직렬화는 영향 없음).

### 타입 추론

| Excel 셀 | Go 타입 |
|---------|---------|
| 정수 (모두 0 이상, uint32 범위) | `uint32` |
| 정수 (큰 값/음수 가능) | `int64` |
| 실수 | `float64` |
| TRUE/FALSE | `bool` |
| 그 외 | `string` |

### PK 표시

첫 번째 컬럼이 PK로 간주되어 주석으로 `// PK`가 추가된다.

## 출력 예시

`input/cards.xlsx`:

| card_id | name | base_atk |
|---------|------|----------|
| 1001 | 강타자 | 100 |

→ `output/cards_design.go`:

```go
// Code generated by excel2struct from cards.xlsx. DO NOT EDIT.
package design

type CardsDesign struct {
	CardId  uint32 `json:"card_id"`  // PK
	Name    string `json:"name"`
	BaseAtk uint32 `json:"base_atk"`
}
```

## 워크플로

1. 기획자가 `input/`에 xlsx 작성
2. `python excel2struct.py --output-dir ../../internal/design`
3. 생성된 `.go` 파일을 그대로 사용 (`DO NOT EDIT` 표시 있으니 직접 수정 금지)
4. `Snapshot` 통합 (Get 메서드, map 필드)은 수동으로 추가
